## 如何集成到订单详情页

由于微信小程序是编译后运行，需要手动修改现有的订单详情页代码来添加评价按钮。

### 修改步骤：

#### 1. 在订单详情页的合适位置添加评价按钮

在 `orderDetail.wxml` 文件中，在订单状态为"已完成"且未评价的情况下，添加评价按钮：

```xml
<!-- 在订单底部操作区域添加 -->
<view wx:if="{{orderStatus === '已完成' && !hasCommented}}" class="action-buttons">
  <tm-button 
    theme="primary" 
    bind:click="handleComment"
  >
    评价服务
  </tm-button>
</view>
```

#### 2. 在 orderDetail.js 中添加处理函数

```javascript
// 添加评价处理函数
const handleComment = () => {
  common_vendor.navigateTo({
    url: `/pages/orderComment/orderComment?orderId=${props.orderId}`
  });
};

// 在获取订单详情时检查是否已评价
const checkIfCommented = (orderId) => {
  api_order_index.getOrderComment(orderId).then(res => {
    if (res.code === 200 && res.data) {
      hasCommented.value = true;
    }
  });
};

// 修改 getOrderDetailHandle 函数，调用 checkIfCommented
```

#### 3. 添加样式（orderDetail.wxss）

```css
.action-buttons {
  margin-top: 30rpx;
  padding: 0 30rpx;
}

.action-buttons .tm-button {
  width: 100%;
}
```

## 功能流程测试

### 测试步骤：

1. **创建测试订单**
   - 确保订单状态为"已完成"

2. **访问订单详情页**
   - 查看是否显示"评价服务"按钮
   - 如果已评价，不应显示按钮

3. **点击评价按钮**
   - 跳转到评价页面
   - 检查是否正确传递了 orderId

4. **提交评价**
   - 选择星级（1-5星）
   - 可选填评价文本
   - 点击提交

5. **验证结果**
   - 评价成功后返回订单详情页
   - 评价按钮应消失
   - 可查看已提交的评价

## 注意事项

1. **订单状态验证**：只有订单状态为"已完成"才能评价
2. **重复评价防护**：一个订单只能评价一次
3. **用户信息获取**：评价时需要获取当前登录用户ID
4. **司机信息获取**：需要从订单详情获取司机ID

## 数据库验证

评价数据保存在 `order_comment` 表中，包含：
- order_id: 订单ID
- driver_id: 司机ID
- customer_id: 顾客ID
- rate: 评分（1-5星）
- remark: 评价备注
- status: 状态（1未申诉）
- create_time: 创建时间
